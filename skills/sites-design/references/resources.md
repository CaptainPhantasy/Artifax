# Resources

The curated knowledge set. Consult these instead of re-deriving fundamentals —
they are the difference between a first draft and a professional result.

## Foundations

- **Refactoring UI** — https://www.refactoringui.com — hierarchy, spacing, color,
  and "make it look designed" heuristics. (Paid; do not bundle.)
- **Laws of UX** — https://lawsofux.com — cognitive principles behind good UI.
- **Every Layout** — https://every-layout.dev — resilient layout primitives
  (Stack, Cluster, Sidebar, Switcher) that replace fragile flex hacks.
- **Inclusive Components** — https://inclusive-components.design — accessible
  patterns for the components everyone gets wrong.

## Typography

- **Practical Typography** (Butterick) — https://practicaltypography.com
- **Fontsource** — https://fontsource.org — self-hosted webfonts, no CDN.
- **Google Fonts** — https://fonts.google.com — for selection/paired specimens.
- **Variable fonts** — https://fonts.google.com/variablefonts

## Rule for using resources

A resource is a **source of principles**, not of code to paste. Translate what
you learn into the site's tokens and components so the result stays coherent.
